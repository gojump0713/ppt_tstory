# 전 세대를 잇는 공공도서관 · AI 시민 동화책 제작 플랫폼 — 인터랙티브 발표자료

`index.html`을 브라우저(Chrome/Edge 권장)에서 열면 바로 발표할 수 있습니다. 서버·설치·네트워크가 필요 없습니다.

## 발표 전 체크
1. `index.html` 더블클릭 → `F` 키로 전체화면
2. 프로젝터 해상도 1920×1080 권장 (1366×768, 16:10 노트북도 자동 레터박스)
3. 발표자 메모가 필요하면 `P` (청중 화면에서는 기본 OFF)
4. 처음 열리면 1장에서 시작하고, 새로고침해도 현재 장표(URL `#slide-NN`)가 유지됩니다
5. 시연은 18장 낭독 후 `Enter`(또는 DEMO 버튼 · `D`)로 시작하고, 끝나면 18장으로 돌아옵니다

## 조작 키
| 키 | 동작 |
|---|---|
| `→` `↓` `Space` `PageDown` · 마우스 휠 아래 · 클리커 다음 | 다음 장표 (한 번에 정확히 한 장) |
| `←` `↑` `PageUp` · 마우스 휠 위 · 클리커 이전 | 이전 장표 |
| `Home` / `End` | 1장 / 18장 |
| `Enter` | 다음 장표 · **18장에서는 시연(DEMO) 시작** |
| `D` | 시연 화면 열기 (어느 장표에서든) |
| `F` | 전체화면 토글 |
| `P` | 발표자 메모 패널 (낭독 멘트 · 배정 시간 · 다음 장표 · 동작 큐) |
| `T` · `O` · `Esc` | 목차 (클릭으로 이동) · 우하단 페이지 번호 클릭도 동일 |
| `S` | 인용 근거 4건 보기 |
| `M` | 모션 최소화 (애니메이션 없이 즉시 최종 상태) |
| `R` | 현재 장표 애니메이션 다시 재생 |
| `Esc` | 열린 패널 닫기 / 시연 종료(18장으로) |

시연 화면 안에서: `→` 다음 화면, `←` 이전 화면, `Backspace`/`Esc` 18장으로 복귀, 마지막 화면에서 `Enter` → 18장으로 복귀.

## 구성
- 18장 + 시연 5화면 (원고 `AI시민동화책_공공도서관_발표멘트_최종.md` 기준 · 제목/거버닝/화면 문구는 화면설계서, 수치 규칙은 PRD)
- 원고의 Ⅰ~Ⅵ 장 구분은 별도 장표 없이 좌상단 Chapter Label로 표시합니다.
- `○○○권`(연간 지역자료)은 임의 숫자로 채우지 않습니다. `js/data.js`의 `METRICS.annualArchiveCount`에 값을 넣으면 화면에 반영됩니다.
- 원고에 【원문 확인】【조문 확인】으로 표시된 출처(독서율 50% 목표, 디지털포용법·AI 기본법)는 `S` 패널과 각주에 확인 필요 표시가 붙습니다. 외부 배포 전 원문을 대조해 `SOURCES[].status`를 `verified`로 바꾸세요.
- 모든 장표는 진입 시 자동으로 순차 재생되고 약 4.5초 안에 최종 상태에 도달합니다. 장표 안에서 클릭할 필요가 없습니다.
- 13장 Before/After는 자동 재생 후 드래그(또는 슬라이더를 클릭한 뒤 `Shift`+`←` `→`)로 다시 비교할 수 있습니다. 일반 `←` `→`는 항상 장표 이동입니다.

## 파일
```
presentation/
├─ index.html            셸 · 아이콘 스프라이트 · 오버레이
├─ css/presentation.css  디자인 토큰 · 장표별 레이아웃 · 모션
├─ js/data.js            제목·거버닝 메시지·낭독 멘트·출처·수치 (단일 관리)
├─ js/slides.js          장표별 비주얼 템플릿 · 진입 시퀀스 · 시연 화면
├─ js/app.js             내비게이션 · 스케일 · 발표자 UI · 미디어 로딩
├─ fonts/                Pretendard Variable
└─ media/                Higgsfield 배경 영상/이미지 슬롯 (README 참고, 없어도 동작)
```

## 문구·수치 수정
`js/data.js`만 고치면 됩니다. 제목·거버닝 메시지는 `SLIDES`, 수치는 `METRICS`(파생값 5.2배·70.2%p 포함), 출처는 `SOURCES`, 낭독 멘트는 각 장표의 `note`입니다. 장표 안의 카드 문구는 `js/slides.js`의 해당 장표 템플릿에 있습니다.
발표자·대상은 `DECK_META`에 있고, 실제 서비스 시연 URL을 쓰려면 `DECK_META.demoUrl`에 주소를 넣으면 18장 DEMO 버튼·`Enter`·`D`가 그 주소를 새 창으로 엽니다(비우면 내장 로컬 시연 화면 5단계: 기획 → 글 다듬기 → 일러스트 → 오디오북 → 실물 출판·사서 관리).

## 지원 범위
PC·노트북·프로젝터 전용입니다. 가로 1024px 미만에서는 안내 화면만 표시하며 모바일 레이아웃은 제공하지 않습니다.
